     Plan: "Approve all" button with grouped Undo

     Context

     The Leave Requests screen (app/LeaveRequestsScreen.tsx) lets a manager
     approve/reject one request at a time, with an Undo button that reverts one
     action per tap. The user wants an Approve all button below the title that:
     - asks first with an alert Approve N pending requests? (N = real live
       count),
     - is disabled when there are no pending requests,
     - and is undone as a single unit — one Undo tap restores every request it
       approved, not just one.

     Today the undo history is a flat list of { id, previousStatus }, so one
     bulk action would take N taps to undo. The fix is to make each history
     entry a group of changes.

     Changes

     1. app/LeaveRequestsScreen.tsx — reducer & history

     - Change history shape so one entry = one user action:
     type Change = { id: string; previousStatus: LeaveStatus };
     type HistoryEntry = { changes: Change[] };
     - decide case: push { changes: [{ id, previousStatus: target.status }] }
       (same behavior as now).
     - New action { type: 'approveAll' }:
       - Collect all requests with status === 'pending'; if none, return state
         (no empty history entry).
       - Set them all to 'approved' and push one entry whose changes lists every
         affected id with previousStatus: 'pending'.
     - undo case: pop the last entry and revert every change in it (build a
       Map<id, previousStatus> from last.changes, map requests through it).
     - Reducer stays the single source of truth; repeat-tap guard for decide
       unchanged.

     2. app/LeaveRequestsScreen.tsx — UI

     - const pendingCount = state.requests.filter(r => r.status === 
       'pending').length;
     - handleApproveAll:
     Alert.alert(`Approve ${pendingCount} pending ${pendingCount === 1 ? 
     'request' : 'requests'}?`, undefined, [
       { text: 'Cancel', style: 'cancel' },
       { text: 'Approve', onPress: () => dispatch({ type: 'approveAll' }) },
     ]);
       (Exact requested text Approve 2 pending requests? for N > 1; singular
       "request" when N = 1.)
     - Render below the title, above the ScrollView, wrapped in a View
       (paddingHorizontal: 16, marginBottom: 12, alignItems: 'flex-start'):
     <ActionButton
       label="Approve all"
       variant="approve"
       disabled={pendingCount === 0}
       onPress={handleApproveAll}
       accessibilityLabel={`Approve all ${pendingCount} pending requests`}
       accessibilityHint="Asks for confirmation, then approves every pending 
     request"
     />
     - Move marginBottom spacing so title → button → table looks consistent
       (title marginBottom 8, button wrapper marginBottom 12).
     - Update Undo accessibilityHint to "Reverts the most recent action,
       including Approve all".

     3. Reuse

     - components/ActionButton.tsx — existing approve variant + disabled
       styling/accessibilityState; no changes needed.
     - components/LeaveTable.tsx — no changes.
     - Only core RN (Alert, View) — no new packages.

     4. checklist.md

     Add Build/Verify items for this feature (per checklist convention), and
     tick them once verified.
